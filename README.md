<h3>This is a full stack web application, which has been made to understand how social media posts are posted onto the platform and how they are shown in the user's feed.</h3>

<h4>To use this application:</h4>

1. clone it
2. open 2 terminals
3. In one terminal navigate to Frontend folder
4. Navigate to Backend folder in another one
5. run "npm i" command in both the terminals
6. run command "npm run dev" oin frontend folder
7. run command "node server.js" in backend folder
8. navigate to "http://localhost:5173/create-post" to create a post
9. After submiting the post, you'll be directed to the feed page, where you can see all the posts
10. If you want to see all the posts without creating any post, navigate to "http://localhost:5173/feed"
